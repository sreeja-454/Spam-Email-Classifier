# Spam Email Classifier

## Overview

This project uses Machine Learning and Natural Language Processing (NLP) to classify messages as **Spam** or **Ham (Not Spam)**.

## Features

* Cleans and preprocesses text data
* Converts text into numerical features using TF-IDF
* Trains a Multinomial Naive Bayes classifier
* Predicts whether a message is spam or not

## Technologies Used

* Python
* Pandas
* NLTK
* Scikit-learn
* TF-IDF Vectorizer
* Multinomial Naive Bayes

## Dataset

SMS Spam Collection Dataset

## Model Accuracy

Approximately 97% accuracy on the test dataset.

## Example Prediction

Input:
Congratulations! You have won ₹1,00,000. Click here to claim.

Output:
Spam
